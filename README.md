# مملكة شيرو | Shiro Kingdom

الصفحة الرسمية الكاملة لمملكة شيرو (صور مدمجة + عداد حي + روابط Elysia و Arise).

## المستودع
https://github.com/AAAA159/shiro-kingdom

## كيف ترفع الصفحة الكاملة (3 ميجا)

1. حمّل ملف `shiro-landing.html` من المحادثة.
2. في هذا المستودع اضغط **Add file → Upload files**
3. ارفع الملف وسمّه `index.html`
4. اعمل Commit

بعد كده فعّل GitHub Pages من Settings → Pages.
